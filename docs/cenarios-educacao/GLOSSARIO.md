# Glossário

**Afirmação diagnóstica**
Frase factual derivada de dados observados. Permanece em Vocações da Região.

**Cenário exploratório**
Configuração alternativa usada para testar mecanismos e decisões. Não recebe probabilidade.

**Campo morfológico**
Combinação controlada de estados possíveis dos fatores críticos.

**Claim ceiling / teto de afirmação**
Limite máximo do que uma fonte permite concluir sem extrapolação.

**Constructo**
Fenômeno que se pretende medir, como colaboração educacional regional. Um proxy só é elegível quando mede esse fenômeno com escopo compatível.

**Digest agregado**
Hash calculado sobre o manifesto interno das entradas, sem publicar a lista municipal detalhada.

**Distância Hamming**
Quantidade de fatores com estados diferentes entre dois cenários.

**Fator**
Incerteza estrutural cujos estados compõem os cenários.

**Lacuna explícita**
Ausência preservada quando a fonte pública não mede o constructo. Não equivale a zero.

**Lente municipal**
Tradução dos mecanismos regionais para a exposição de Nova Santa Rita, sem classificá-la em um cenário.

**Maturidade transversal**
Estatuto da evidência disponível para um tema: sentinela pública, série observada, contexto reconciliado ou lacuna explícita.

**Opção contingente**
Ação ativada somente quando um gatilho verificável ocorre.

**Opção robusta**
Preparação útil em mais de um futuro, sem pressupor qual ocorrerá.

**Ponte diagnóstica**
Vínculo por rota, hash e ID entre Cenários e Vocações, sem copiar narrativa.

**Sentinela**
Indicador usado para revisar premissas no checkpoint, não para escolher automaticamente um futuro.

**Stress-test do PNE**
Teste qualitativo de como condições de execução diferentes favorecem ou pressionam os mesmos compromissos normativos.

**Zero observado**
Valor medido igual a zero. É diferente de null, indisponível, suprimido e não aplicável.
